# solids-world

> An open-source, interactive 3D atlas for **solid-state and atomic physics** — a desktop app that turns Bravais lattices, electron orbitals, symmetry operations and lattice vibrations into worlds you can rotate, slice and play with. **Out of the box, fully offline**, for Windows and Linux.

![Status](https://img.shields.io/badge/status-active_development-blue) ![License](https://img.shields.io/badge/license-MIT-green)

**The Chinese [README.md](README.md) is the source of truth for this repository.** This file is a condensed translation.

## What it is

- A **3D study atlas**: one crystal structure or orbital per entry, each with a procedural 3D model, key facts, a step-by-step guided tour (the camera follows the narration) and a mini quiz;
- **Four sections**: Crystal Structures (all 14 Bravais lattices + classic, metal and functional-material structures), Atoms & Orbitals (isosurfaces, phases, nodes), Symmetry (apply symmetry operations by hand), Dynamic Demos (lattice waves, thermal expansion);
- **CIF rendering**: drop a `.cif` file onto the window (or open it from the app menu), parsed locally into an instant 3D view;
- **Procedural geometry**: all 3D content is generated by code from physics formulas — zero external model assets, runs fully offline.

## Features

### Atlas content — 53 entries, bilingual (Chinese & English), growing

| Section | Entries | Covers |
|---|---|---|
| Crystal Structures | 12 | Classics such as rock salt, diamond and CsCl; common metal structures; functional materials such as perovskite |
| Bravais Lattices | 14 | All 14 Bravais lattices across the seven crystal systems |
| Atoms & Orbitals | 11 | Orbital shapes (isosurface/phase/nodes), electron cloud, atomic models, energy levels & transitions |
| Symmetry | 11 | Rotation/reflection/inversion/screw & glide operations, common point groups, intro to space groups |
| Lattice Dynamics | 5 | Monatomic/diatomic chain waves, 3D vibrational modes, thermal expansion |

### Interaction & learning

- **Step-by-step lessons**: camera moves and structure hotspots highlight in sync with each narration step;
- **Quizzes**: take a quiz after the lesson; passes are tracked per entry;
- **Notes**: write notes on any entry, browse them all in one overview, and export everything to Markdown;
- **Gallery**: an overview of every entry with lesson/quiz completion status;
- **Search**: by Chinese name, English name, alias, or Chinese pinyin — press `/` to focus the search box;
- **3D controls**: supercell toggle (1×/2×), bond and atom-label switches, clipping planes, manual rotation and pause; orbital entries expose isosurface threshold, phase mode, opacity, nodal-plane visibility and radial range;
- **Parametrized animation**: symmetry and dynamics entries support play/pause, speed control, single-step advance, and sliders for physical parameters such as wavelength and frequency;
- **Locale & theme**: one-click Chinese/English switching; light/dark/system themes; respects the OS "reduce motion" setting;
- **Keyboard shortcuts**: arrow keys to move between entries, `/` for search, `F` to focus the 3D stage, `Ctrl/⌘+D` for a random entry, `Esc` to close a dialog or reset the view.

### CIF support

- **Fully local parsing**: drag-and-drop or menu-open `.cif` files; the built-in parser handles lexing, syntax checking, symmetry-operation expansion and space groups, with no network access;
- **Error reporting**: clear messages for syntax errors, unknown space groups, oversized files and similar problems;
- **Recent files**: up to 10 recently opened CIFs are remembered;
- **Bundled samples**: `resources/cif-samples/` ships several example structures (including one deliberately broken file used to exercise error handling).

## Status

The core desktop app is working: all 53 entries across the four sections ship with lessons and quizzes; CIF parsing and 3D rendering, note export, persistent settings, bilingual UI and light/dark themes are all in place.

The test suite currently contains **21 test files / 161 tests**, covering CIF parsing (including broken files and uncertainty tags), search/pinyin and data contracts, the seams between 3D builders and lesson anchors, model-cache eviction, and the main UI components — all passing. Content and polish keep being added.

## Run from source

Requirements: **Node.js ≥ 22**.

```bash
npm install        # install dependencies
npm run dev        # start the Vite dev server and launch the Electron window
npm test           # run the full test suite (Vitest)
npm run typecheck  # type-check both main and renderer code
npm run build      # build renderer and main-process output
```

Build local installers (build artifacts are not committed to the repository):

```bash
npm run dist        # build both Windows and Linux packages
npm run dist:win    # Windows only: NSIS installer
npm run dist:linux  # Linux only: AppImage and deb
```

## Project layout

```
electron/   Electron main process: window & menu, settings/notes persistence, CIF parser, IPC, logging
src/        Renderer: React components, bilingual atlas data, Three.js stage and per-entry 3D builders, i18n, themes
resources/  App icons and bundled CIF samples
scripts/    Build helper scripts (space-group data generation)
```

## Relationship with insect-world

The information architecture and engineering methodology are inspired by the open-source project [insect-world](https://github.com/xr843/insect-world) (MIT), with thanks. **No code or color scheme is copied**:

- solids-world is an offline desktop app (Electron) rather than a web app;
- its visual system is an original "physics classroom" dual theme (cool chalkboard / handout palette) that deliberately opposes insect-world's warm "museum" palette (brass / specimen paper) in color temperature, hue and metaphor;
- the 3D content, physics-domain material and internationalization approach are all independently implemented.
