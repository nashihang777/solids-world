# solids-world · 固体世界

> 一个专为**固体物理与原子物理**打造的**开源可交互 3D 图鉴**桌面软件——让布拉维格子、电子轨道、对称操作与晶格振动变成可以亲手旋转、剖开、播放的立体世界。**开箱即用、完全离线**，支持 Windows 与 Linux。

![状态](https://img.shields.io/badge/状态-积极开发中-blue) ![许可](https://img.shields.io/badge/license-MIT-green)

## 这是什么

- **一本立体教具书**：按"图鉴条目"组织（一个晶体结构/一个轨道 = 一个条目），每条配有程序化 3D 模型、关键数据、分步讲解（讲到哪、镜头转到哪）与小测验；
- **四大板块**：晶体结构（14 布拉维格子 + 经典/金属/功能材料结构）、原子与轨道（等值面/相位/波节）、对称性专题（可亲手施加对称操作）、动态物理演示（格波/热膨胀等可播放）；
- **CIF 渲染**：把自己的晶体结构文件（.cif）拖进窗口（或通过应用菜单打开），本地解析、立即成 3D；
- **程序化生成**：全部 3D 几何由代码按物理公式现算现画，零外部模型文件，完全离线运行。

## 功能

### 图鉴内容（53 个条目，中英双语，持续增加中）

| 板块 | 条目数 | 覆盖内容 |
|---|---|---|
| 晶体结构 | 12 | 岩盐、金刚石、氯化铯等经典结构，常见金属结构，以及钙钛矿等功能材料结构 |
| 布拉维格子 | 14 | 七大晶系全部 14 种布拉维格子 |
| 原子与轨道 | 11 | 轨道形状（等值面/相位/波节）、电子云、原子模型、能级与跃迁 |
| 对称性 | 11 | 旋转/反映/反演/螺旋滑移等对称操作、常见点群、空间群入门 |
| 晶格动力学 | 5 | 单原子与双原子链格波、三维振动模式、热膨胀等动态演示 |

### 交互与学习

- **分步讲解**：每个条目都有分步讲解，镜头与标注热点随讲解节奏联动；
- **小测验**：讲完即测，通过情况自动记入条目学习进度；
- **学习笔记**：逐条目记笔记，支持汇总浏览与一键导出为 Markdown；
- **图鉴画廊**：总览全部条目及各条目的讲解完成、测验通过状态；
- **搜索**：支持中文、英文、别名与拼音检索，`/` 即可聚焦搜索框；
- **3D 操控**：超胞切换（1×/2×）、成键开关、原子标签、剖切平面、手动旋转与定格；轨道条目可调节等值面阈值、相位模式、不透明度、波节显示与径向范围；
- **参数化动画**：对称演示与动力学条目支持播放/暂停、调速、单步推进，并可用滑块改变波长、频率等物理参数；
- **双语与主题**：中文/英文一键切换；浅色/深色/跟随系统三种主题模式；尊重系统"减少动态效果"设置；
- **键盘快捷键**：方向键切换条目、`/` 聚焦搜索、`F` 聚焦 3D 舞台、`Ctrl/⌘+D` 随机一条、`Esc` 关闭弹层或重置视角。

### CIF 晶体结构文件支持

- **完全本地解析**：拖放或菜单打开 `.cif`，由内置解析器完成词法、语法、对称操作展开与空间群处理，全程不联网；
- **错误提示**：语法错误、未知空间群、文件过大等情况会给出明确提示；
- **最近文件**：自动记录最近打开的 CIF（最多 10 个）；
- **内置样例**：`resources/cif-samples/` 提供多份示例结构文件（其中包含一份用于验证错误处理的损坏样例）。

## 从源码运行

环境要求：**Node.js ≥ 22**。

```bash
npm install        # 安装依赖
npm run dev        # 启动 Vite 开发服务器并自动拉起 Electron 窗口
npm test           # 运行全部测试（Vitest）
npm run typecheck  # 类型检查（主进程 + 渲染层）
npm run build      # 构建渲染层与主进程产物
```

打包本地安装包（安装包产物不纳入版本库）：

```bash
npm run dist        # 同时打包 Windows 与 Linux
npm run dist:win    # 仅 Windows：NSIS 安装程序
npm run dist:linux  # 仅 Linux：AppImage 与 deb
```

## 目录结构

```
electron/   Electron 主进程：窗口与菜单、设置/笔记持久化、CIF 解析器、IPC、日志
src/        渲染层：React 组件、图鉴数据（中英双语）、Three.js 场景与各条目 3D 构建器、i18n、主题
resources/  应用图标与内置 CIF 示例
scripts/    构建辅助脚本（空间群数据生成）
```

## 与参考项目 insect-world 的关系（重要声明）

本项目的信息架构与工程方法论受开源项目 [insect-world](https://github.com/xr843/insect-world)（MIT）启发，特此致谢。**本项目不复制其代码与配色**：

- 交付形态不同：离线桌面应用（Electron） vs 网页应用；
- 视觉体系不同：本项目采用"物理教室"双主题（冷色黑板/讲义），与其"博物馆"暖色体系（黄铜/标本纸）在色温、色相、隐喻上系统性对立；
- 3D 内容、物理领域内容、国际化方案均为独立实现。
